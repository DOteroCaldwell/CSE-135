HW2 — Server-Side Basics

The same five programs, written three times over.

What this is

Five CGI programs — a HTML greeting, the same greeting as JSON, an environment dump, a request echo, and a server-side session demo — implemented independently in PHP, Go and Python. The point is how little the language changes: every one of them reads the same CGI environment, parses the same request body off standard input, and writes the same headers.
